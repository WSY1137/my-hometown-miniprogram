# 我的家乡 · 香格里拉 微信小程序

## 项目简介

本项目是一个以「香格里拉」为主题的微信小程序，集图文展示、背景音乐、视频播放与「家乡印记」互动社区于一体。用户可以在首页浏览香格里拉的自然风光、历史文化与民族风情介绍，同时通过「家乡印记」模块发布、浏览、点赞和删除关于家乡的照片与文字印记。

项目采用微信小程序原生框架 + 微信云开发（CloudBase）技术栈，历经多个版本迭代，最终采用第七版作为发布版本。

## 功能特性

- **首页展示**：香格里拉图文介绍（自然景观、历史文化、民族风情、红色记忆），支持滚动浏览。
- **背景音乐播放**：内置背景音乐，支持播放/暂停/回到开头，带实时进度条与时间显示。
- **视频播放**：视频播放、暂停、重新播放，含播放错误提示。
- **家乡印记模块**：
  - 发布印记：标题、内容、类型（景点/美食/故事）、最多 9 张图片，带表单校验与字数统计。
  - 草稿功能：本地自动/手动保存草稿，重新进入可恢复。
  - 印记列表：热门印记（点赞 Top5）+ 最新印记，时间友好展示。
  - 印记详情：图文详情、点赞（防重复）、作者删除（权限校验）。

## 技术栈

- 微信小程序原生框架（自定义导航栏、Skyline 渲染可选）
- 微信云开发 CloudBase
  - 云数据库：`hometown_imprints` 集合
  - 云存储：印记图片上传
  - 云函数：`getUserOpenid`、`getHotImprints`、`likeImprint`、`deleteImprint`

## 数据库设计

集合：`hometown_imprints`

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| title | string | 印记标题 |
| content | string | 印记内容 |
| type | object | 类型 `{ id, name }`（scenic 景点 / food 美食 / story 故事）|
| images | array | 云存储图片 fileID 列表 |
| authorOpenid | string | 作者 openid |
| likeCount | number | 点赞数 |
| likeUsers | array | 点赞用户 openid 列表（防重复点赞）|
| createTime | date | 创建时间 |
| updateTime | date | 更新时间 |

## 开发过程

项目从基础模板起步，先后经历了页面搭建、云开发环境接入、家乡印记模块（发布/列表/详情/点赞/删除）的逐步完善，并进行了自定义导航栏、表单校验、草稿恢复等细节打磨，最终在第七版定型为发布版本。开发过程中重点解决了云函数权限控制、防重复点赞、图片上传与列表刷新等问题。

## 部署说明

1. 使用微信开发者工具导入本项目根目录。
2. 在 `app.js` 中确认已使用默认云环境（未硬编码环境 ID）；若默认环境与预期不符，可在 `wx.cloud.init` 中手动指定 `env`。
3. 在云开发控制台创建数据库集合 `hometown_imprints`，权限建议设为「仅创建者可读写」或配合云函数使用。
4. 分别右键 `cloudfunctions` 下的四个云函数目录，选择「上传并部署：云端安装依赖」。
5. 确认首页视频域名已加入小程序「业务域名/downloadFile 合法域名」白名单（开发阶段可在开发者工具中勾选「不校验合法域名」）。

## 总结

本项目完整实现了「图文展示 + 音视频播放 + 云开发互动社区」的典型微信小程序闭环，涵盖了小程序前端开发、自定义组件、云数据库、云存储与云函数等核心知识点，是一个较为完整的课程设计/实践项目。
